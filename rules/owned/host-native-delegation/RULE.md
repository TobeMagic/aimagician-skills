# Host-Native Delegation

HOST is injected by Skillbird at install time. Spawn that host's native subagent only.

Do not delegate: one or two known files, a fact already in context, unlocked product or architecture decisions, security acceptance, or final completion judgment.

Do delegate when it saves controller context: many unknown files, independent review of a frozen diff, a long isolated check, or parallel lanes with exclusive write scope.

Every worker prompt names: OBJECTIVE, ALLOWED_SCOPE, FORBIDDEN_SCOPE, PERMISSION_MODE, STATUS_PROTOCOL (DONE | DONE_WITH_CONCERNS | NEEDS_CONTEXT | BLOCKED). The controller keeps architecture, safety, and the completion claim.

OpenCode/Codex/Cursor as a foreign runtime is opt-in only (archived cli-agent-delegator, or the user named it).
