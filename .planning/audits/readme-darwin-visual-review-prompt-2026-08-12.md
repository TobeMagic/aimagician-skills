# README Visual Review Prompt

Review the two supplied Skillbird README visuals as product-facing repository assets.

For each image, report only sanitized textual evidence and separate:

- direct observations about composition, hierarchy, legibility, contrast, density, and visible product meaning;
- reasonable inferences about the intended audience and workflow communication;
- uncertainty or claims that cannot be verified from pixels alone.

Check the following acceptance questions:

1. Does the static hero communicate Skillbird as a local-first owned Skill catalog rather than a generic AI illustration?
2. Does the dynamic-demo poster communicate the real catalog-to-agent synchronization workflow and the global/project installation boundary?
3. Are the layouts, typography, contrast, spacing, and visual hierarchy suitable for a GitHub README first viewport?
4. Do the visuals avoid fake logos, unreadable pseudo-copy, accidental third-party branding, and decorative elements that obscure the product?
5. Identify any Blocker, Important, or Nitpick visual issue and state a concrete correction if one exists.

Do not infer implementation behavior that is not visible in the images. Do not expose image bytes, secrets, request metadata, or local filesystem details.
