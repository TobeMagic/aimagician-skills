# Phase 33 Plan 01: Consulting Vertical Tracer and Four-Pack Upgrade

**Status:** Ready for review
**Requirements:** P33-ASSET-01..03, P33-COMP-01,
P33-DESIGN-01..02, P33-WEAK-01

## Wave 1 — Contract and red tests

1. Add strict materialized-asset and manifest models.
2. Add failing tests for required assets left `planned`, invalid provenance,
   provider failure, crop evidence, and renderer integration.
3. Add failing tests requiring all four DesignPacks to load as v2.
4. Freeze R6 as a Quality v3 and direct-review failing baseline, with explicit
   red assertions for missing anchors, flat rhythm, repetitive shells, weak
   hierarchy, disconnected process geometry, weak evidence pages, and asset
   polish.

## Wave 2 — Materialization tracer

1. Add deterministic user/template/licensed/generated/native resolution.
2. Connect Agnes Image output to frozen files and governed AssetBindings.
3. Materialize charts and diagrams as native editable assets.
4. Emit a machine-readable resolution trace for every PlannedAsset.
5. Verify provider failure chooses the declared native fallback without fact
   loss.

## Wave 3 — Consulting authored compositions

1. Register image-led cover/section/case variants and asymmetric data/process
   variants.
2. Make CompositionPlan select them from role, semantic kind, density, energy,
   available asset kind, and recent-layout history.
3. Render the selected anchor and motif as real objects, not decision-trace
   labels.
4. Add deterministic copy fitting and local language lint for section labels,
   orphan lines, pipe separators, and empty numbered cards.
5. Add a composition-floor validator that reports dominant-anchor coverage,
   asymmetric coverage, maximum repeated-layout run, and exact offending
   slides.

## Wave 4 — R7+ visual loop

1. Render the full 14-slide consulting proposal.
2. Run OOXML, editability, LibreOffice, PDF/PNG, preview, and Quality v3 gates.
3. Run direct Agnes on representative full-resolution pages plus deck contact
   sheet.
4. Apply at most two bounded repair passes per candidate.
5. Version every candidate; never overwrite R6.
6. Continue until P33-DESIGN-02 passes or a genuinely external blocker is
   proven.

## Wave 5 — Remaining DesignPacks

1. Upgrade product, data/research, and institutional packs to schema 2.0.
2. Validate all fifteen scenario mappings and distinct visual identities.
3. Generate one proof deck per pack using the same asset and quality seams.
4. Checkpoint each pack separately: schema v2, scenario mapping, native
   editability, materialized required assets, composition-floor PASS, Quality
   v3 PASS, direct visual PASS, and portable proof PASS.
5. Hand all four accepted artifacts to Phase 34 only after every checkpoint
   passes.
