# Phase 45 Context

Phase 44 certified 288 visually reviewed private pages, including 129
direct-use pages, but deliberately did not claim that production could
materialize them. Phase 45 closes the narrower execution gap for the current
three certified spines and establishes a truthful evidence contract that later
private-page materializers must satisfy.

The existing portable native renderer is the accepted COM-free production
engine. The institutional physical pack remains a separate lossless OOXML
adapter. This phase joins selection to those real engines without weakening
source integrity, editability, or fail-closed behavior.

## Implementation Decisions

- Registered candidates bind exact layout IDs before render.
- Physical candidates execute as one hash-bound pack.
- Evidence is typed and serialized with production artifacts.

## Existing Patterns To Preserve

- Deterministic registry loading and digest drift checks.
- Source-safe atomic TemplatePack adaptation.
- Portable COM-free native rendering.
- Weak-model prohibition on raw geometry and styling authority.

## Allowed Scope

Template intelligence, generation/compiler/render integration, TemplatePack
bridge, CLI artifacts, schemas, tests, and Phase 45 evidence.

## Forbidden Scope

Private bytes, credentials, fabricated evidence, source overwrite, silent
fallback, or a new unverified OOXML graph cloner.

## Integration And Compatibility

Auto selection activates only for a certified spine. Explicit candidate choices
are always strict. Existing unsupported scenarios continue through their
current path until Phase 47 expands certified spine coverage.
