## Explicit Non-Passes

- A 15-page deck is not a pass merely because it has 15 pages.
- LibreOffice-only rendering is not PowerPoint evidence.
- A complete single-source deck replay is not mixed-library acceptance.
- A model self-score, a contact-sheet-only inspection, or an output without
  source/component lineage is not release evidence.
- A dated-milestone page cannot be relabelled as `process` merely because a
  timeline/roadmap with the exact certified group count is unavailable.
