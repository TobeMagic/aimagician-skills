## Goal

Extend the accepted authoring system to all fifteen realistic scenarios and
measure whether an ordinary model can reliably make bounded semantic choices
without raw visual or engineering authority.

## Acceptance criteria

- [x] **GOAL-47-01:** All fifteen locked realistic briefs contain detailed
  facts, audience, decision context, timing, material roles, prohibitions,
  cover/directory/sections/body/decision/closing/appendix anatomy, and stable
  digests.
- [x] **GOAL-47-02:** A real ordinary-model run covers every scenario; each
  accepted plan references every active fact exactly once, uses only
  registered beats/semantics, and contains no geometry, style, code, invented
  fact, or self-scoring authority. Provider unavailability is reported rather
  than silently replaced.
- [x] **GOAL-47-03:** Every scenario produces a native editable PPTX, manifest,
  portable render proof, and complete contact sheet with no page-count,
  package, external-link, notes, or whole-slide-raster failure.
- [x] **GOAL-47-04:** Fresh independent visual-capable AI review finds no
  unresolved Blocker or Important, verifies complete-deck anatomy, and does
  not identify the twelve non-flagships as one mechanically recolored layout.

## Engineering contract

The ordinary model returns only `BriefPlan v1`: registered scenario archetype,
four to eight semantic groups, exact fact references, registered beat hints,
registered semantic hints, importance, and bounded preferences. Deterministic
code owns copy, layout, typography, theme, component geometry, materialization,
QA, repair, and release.

The scenario renderer consumes model fact order only when a validated,
hash-bound plan exists. Missing or invalid plans cannot be presented as an
ordinary-model success.
