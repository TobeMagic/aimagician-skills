# Phase 47 Context

Phase 46 established three accepted visual anchors. Phase 47 must prove that
the same deterministic art-direction layer can cover the complete fifteen
scenario corpus while an ordinary model owns only closed-world fact grouping
and ordering.

The user explicitly rejected generic trials, shallow requirements, missing
directory/section pages, and repeated simple card decoration. The twelve
non-flagship briefs therefore remain realistic locked client simulations with
quantitative facts, audience, decision, timing, required assets, prohibitions,
and complete-deck anatomy. A successful model response does not authorize
coordinates, colors, fonts, template IDs, code, QA scores, or release.

The first Phase 47 implementation slice generates all fifteen editable decks
with six scenario theme systems and complete anatomy. It is a baseline, not an
automatic visual acceptance: repetition across scenario families and
scenario-specific chart/diagram depth still require independent review and
iteration.
