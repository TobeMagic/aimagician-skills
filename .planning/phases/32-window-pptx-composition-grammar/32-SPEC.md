# Phase 32 Specification: Composition Grammar and Generated Reference Floor

**Status:** In progress
**Risk:** high
**Requirements:** V51-DESIGN-01, V51-DESIGN-02, V51-DESIGN-03, V51-DESIGN-04

## Goal

Turn semantic narrative intent into reusable, capacity-bounded page
compositions whose real layout variant selection is governed by the Skill
rather than improvised by the model.

## First tracer

The first lane is a Chinese consulting project proposal using the
`consulting-executive` DesignPack.

## Locked requirements

1. Scenario grammar selects recipe, family, variant seed, density, emphasis,
   components, and capacity without model-authored coordinates.
2. Exact source lists in Chinese and English become native editable
   process/timeline/matrix/risk components without paraphrase.
3. Recipe IDs survive VisualPlan, CompiledDeck, and RenderPlan selection.
4. Unsupported semantic/recipe combinations fall back through the existing
   capacity-safe family resolver rather than manufacturing empty peers.
5. A real 9–14 slide proposal must pass portable OOXML, LibreOffice, Quality
   v2, generated richness, and manual contact-sheet review.
6. Automatic PASS is not visual acceptance.

## Current tracer verdict

R2 passes all engineering gates and improves structured page density, but
manual review remains `PARTIAL_NOT_REFERENCE_GRADE`. Phase 32 is not complete.
