# Phase 37: Secure Acquisition and Catalog - Plan 01

**Created:** 2026-07-29
**Requirements:** V6-ASSET-01, V6-LIB-01
**Status:** Accepted

## Objective

Deliver a public-metadata, no-auth vertical tracer for safe template-library
management, leaving authenticated commercial sync explicitly `NEEDS_AUTH`.

## Non-Goals

- Do not access, download, commit, or redistribute commercial template bytes.
- Do not accept cookie values through argv, environment variables, logs, or
  tracked files.
- Do not implement TemplatePack v2, final selection planning, or flagships.
- Do not make COM or HTML conversion part of acquisition.

## Tasks

### Task 1: Versioned contracts

**Requirements:** V6-ASSET-01, V6-LIB-01

Add acquisition-manifest, quarantine-report, rights-record, and Catalog v3
schemas with status enums, stable IDs, lineage, resumable state, findings,
certification, dependencies, geometry/capacity/style/editability, and query
results. Implement the field, enum, conditional-requirement, stable-ID,
dedupe, pHash-state, and certification-threshold table locked in `37-SPEC.md`;
all schemas use Draft 2020-12 and reject unknown or secret-bearing fields.

**Acceptance:** valid examples pass Draft 2020-12; unknown fields,
secret-bearing fields, unsafe statuses, pending pHash visual ranking, and
incomplete certified items fail.

### Task 2: Security and resumable state

**Requirements:** V6-ASSET-01

Implement `acquisition.py` and `quarantine.py`: private-root resolution,
redacted credential loading, host allowlist, redirect authorization policy,
passive ZIP classification, content hashing, dry-run intents, and atomic state.

**Acceptance:** default calls write nothing; applied state stays below a temp
private root; unsafe packages quarantine; secrets never appear in results.

### Task 3: Catalog v3 and compatibility

**Requirements:** V6-LIB-01

Implement `catalog.py`, a public metadata seed, stable content IDs, hash
dedupe, legacy adapter, certified-only retrieval, rights/scenario/style/
capacity filters, deterministic ranking, and dependency closure.

**Acceptance:** seed query passes; identical hashes dedupe; legacy entries
never auto-select; missing/cyclic/uncertified dependencies fail closed.

### Task 4: Dedicated JSON manager CLI

**Requirements:** V6-ASSET-01, V6-LIB-01

Add `manage_window_pptx_library.py` exposing
`discover|sync|ingest|certify|query`. Mutation requires `--apply`; credential
input is a private path and only valid for sync.

**Acceptance:** five command routes have no-auth/dry-run coverage; invalid
scope and rights fail closed; output never contains fixture secrets.

### Task 5: Verification and audit

Run focused and affected tests, justified full shards, formatter, workflow,
private staged guard, and diff checks. Obtain independent specification,
quality, verification, and Agnes completion reviews; resolve every Blocker and
Important.
