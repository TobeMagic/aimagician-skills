# Phase 49: Physical Template Assembly and Work-Report Acceptance - Plan 01

**Created:** 2026-08-08
**Requirements:** V61-LIB-01, V61-SEL-01, V61-ASM-01, V61-ADAPT-01, V61-QA-01, V61-CLEAN-01, V61-REL-01
**Requests:** USR-V61-01
**Status:** Approved

## Objective

Stabilize the v6.1 physical template path, prove it on synthetic and private
fixtures, then run one external clean-room Codex work-report acceptance and
close only after independent reviews and delivery evidence.

## Non-Goals

- `pptx-studio` rename/removal, private-asset pruning, and Agnes semantic index.
- Broad multi-scenario expansion, mandatory COM, raster output, or arbitrary
  model-written geometry/style/code.

## Tasks

### Task 1: Correct page intelligence and safe retrieval

**Requirements:** V61-LIB-01, V61-SEL-01
**Depends on:** None
**Slice:** Tracer
**Allowed files:** page-template library module, its v1/v4 schemas, v6.1
library CLI wiring, and focused page-library tests.
**Forbidden files:** physical assembler, private assets, unrelated registries,
and v7 naming paths.

1. Add failing fixtures proving slide 2 differs from slide 1 and
   reference-only pages are excluded by default.
2. Read the requested slide/relationships, preserve pool/decision/direct-use,
   and derive deterministic structural/palette style features.
3. Keep scoring deterministic and fail closed for incompatible or ineligible
   candidates.
4. Compile the real 288-page core and inspect counts, styles, and direct-use
   query results.

**Acceptance:** GOAL-49-01 and GOAL-49-02 PASS.
**Integration points:** certified-core manifest, page-template v1, library v4,
query CLI.
**Checkpoint:** Record changed files, command output, review status, and next task.

### Task 2: Replace per-slide copying with complete OPC graph assembly

**Requirements:** V61-ASM-01, V61-ADAPT-01, V61-QA-01
**Depends on:** Task 1 public record contract
**Slice:** Boundary
**Allowed files:** physical assembly/rule-QA modules, physical report schema,
assembly CLI wiring, and focused synthetic/private assembly tests.
**Forbidden files:** private source mutation, arbitrary visual renderer, COM
write automation, and unrelated skill modules.

1. Add recursive chart/style/color/workbook, media dedup, repeated-source, and
   unsafe-target fixtures that fail for the checkpoint implementation.
2. Add assembly-wide and per-source contexts; resolve every relationship
   relative to its owner and preallocate target slide paths.
3. Preserve content types; share same-source immutable dependencies and
   conservatively deduplicate only safe byte-identical static parts.
4. Adapt declared native text slots after closure and preserve editable
   charts/media/theme geometry.
5. Traverse every internal output relationship and emit unresolved, dedup,
   dependency, lineage, size, and amplification metrics.
6. Run the 15-slide private replay and enforce zero unresolved plus the 1.30x
   package-size gate.

**Acceptance:** GOAL-49-03 and GOAL-49-04 PASS.
**Integration points:** assembly-plan v1, physical-assembly report, renderer
CLI, `python-pptx`, LibreOffice.
**Checkpoint:** Freeze output/report hashes and record any remaining gate.

### Task 3: Clean-room Codex generation and independent closure

**Requirements:** V61-CLEAN-01, V61-REL-01
**Depends on:** Tasks 1 and 2; no unresolved engineering gate
**Slice:** Cleanup
**Allowed files:** ignored external requirement/output folder, Phase 49
validation/UAT/audit/summary, Skill workflow docs, and install synchronization.
**Forbidden files:** reference PPTX or private bytes in the client folder,
reviewer context sharing, self-scoring, and v7 migration changes.

1. Build and inspect the complete public 15-slide requirement pack.
2. Synchronize the frozen source Skill and verify source/install digest parity.
3. Run the exact external Codex `gpt-5.6-terra` medium command from a new clean
   folder and require one editable PPTX plus evidence bundle.
4. Run structural/recursive/portable/lineage/size gates and render the output.
5. Obtain three fresh anonymous visual reviews and a fresh frozen-point
   OpenCode completion audit; fix and repeat on any Blocker or Important.
6. Update validation/UAT/audit/context promotion, merge, push, resync, and
   verify the final installed digest.

**Acceptance:** GOAL-49-05 and GOAL-49-06 PASS; no `FAIL` or `NOT_RUN` remains.
**Integration points:** clean requirement pack, Codex CLI, Skillbird install,
visual review, OpenCode audit, Git delivery.
**Checkpoint:** Phase and milestone closure records identify implementation
merge SHA and final install digest.
