## Portable Scenario Matrix

Run the six frozen calibration scenarios: business report, data analysis, e-commerce/marketing, investor pitch, product launch, and training.

For each scenario:

1. Compile immutable facts through BriefPlan, NarrativePlan, DeckPlan, and RenderPlan.
2. Generate the portable PPTX without COM.
3. Verify deterministic package normalization and OOXML semantic parity.
4. Export PDF through an isolated LibreOffice profile and PNG through Poppler.
5. Run Quality-v2 and the bounded repair contract.
6. Inspect the contact sheet for hierarchy, crop, whitespace, repetition, font fallback, chart labels, brand consistency, and absence of raster-slide fallback.
7. Verify source/candidate hashes, artifact manifest, native/editable identities, and process/profile cleanup.

The matrix must collectively cover 16:9, 4:3, a custom ratio, text, shapes, images, tables, charts, all six diagram families, notes, links, masters, and footers.

## Failure And Recovery Matrix

- Required animation/SmartArt/native grouping/physical-template import in portable mode fails before candidate creation.
- Broken relationship, missing Content Type, object mismatch, missing chart data, or malformed link fails before promotion.
- Missing LibreOffice/Poppler, timeout, unreadable PDF/PNG, or missing page fails portable verification and cleans the isolated profile.
- Long CJK text, missing font, dense chart labels, crop stress, and insufficient assets either repair monotonically or fail closed without changing facts.
- HTML proof failure does not change the PPTX hash or delivery verdict.
- COM unavailable or early-bound WPS-polluted does not affect portable PASS.
- A pre-existing unowned PowerPoint process makes optional certification fail closed and remains untouched.
