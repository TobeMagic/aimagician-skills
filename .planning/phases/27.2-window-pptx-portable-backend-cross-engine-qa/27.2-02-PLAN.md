# Plan 02: OOXML Inspector, LibreOffice Proof, and HTML Boundary

**Requirements:** V5-PORT-04, V5-PORT-05, V5-PORT-06
**Status:** Accepted

## Objective

Make portable delivery independently verifiable without resaving the canonical PPTX or treating HTML as a production renderer.

## Tasks

- [x] Add failing positive and corrupted-package fixtures for content types, relationships, geometry, identities, text, images/crops, charts/workbooks, tables, notes, links, masters, and duplicate IDs.
- [x] Implement RenderPlan-aware OOXML inspection with stable finding codes and hard-gate integration before promotion.
- [x] Install and fingerprint WSL LibreOffice Impress; validate `pdfinfo` and `pdftoppm` availability/version.
- [x] Implement isolated per-run LibreOffice profiles, candidate-copy PDF export, timeout/cleanup, Poppler PNG conversion, and page-count/ratio/readability checks.
- [x] Route real LibreOffice PNGs through existing Quality-v2 and bounded repair while proving the canonical PPTX hash never changes.
- [x] Implement deterministic RenderPlan-derived HTML proof pages using governed tokens, with no path from HTML to canonical PPTX generation.
- [x] Add failure and recovery tests for missing executables, conversion timeouts, truncated output, unreadable pages, Chinese/space paths, and process/profile residue.

## Verification

- All OOXML positive/negative fixtures return expected stable results.
- LibreOffice/Poppler integration passes for 16:9, 4:3, custom ratio, Chinese paths, and paths containing spaces.
- Candidate hashes match before/after rendering and no temporary profile or process remains.
- HTML proof determinism and non-interference tests pass.
- Quality-v2 uses actual LibreOffice PNG evidence and fails closed when it is absent or invalid.

## Rollback And Recovery

LibreOffice operates on a candidate copy only. On timeout or failure, preserve sanitized logs and candidate evidence, remove the isolated profile, and stop before promotion. HTML proof failure is reported separately and cannot mutate the deck.
