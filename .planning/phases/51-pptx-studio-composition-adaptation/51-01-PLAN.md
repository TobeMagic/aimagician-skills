# Phase 51: Composition Retrieval and Governed Adaptation — Plan 01

**Created:** 2026-08-12
**Requirements:** V7-COMPOSE-01, V7-ADAPT-01
**Status:** Accepted

## Objective

Provide deterministic composition and fact-bound adaptation compilers on top
of Phase 50 catalog data, establishing the exact capability boundary that a
mid/high-tier agent will use before later physical PPTX assembly.

## Non-Goals

- PPTX import, slide rendering, QA repair, installed Skill migration, or
  source-tree rename/removal.
- Model calls, filesystem discovery, client-folder scans, direct private asset
  reads from the compilers, arbitrary OOXML/geometry/style instructions.

## Tasks

### Task 1: Lock composition and adaptation public contracts

**Requirements:** V7-COMPOSE-01, V7-ADAPT-01
**Depends on:** Phase 50 complete
**Slice:** Boundary

1. Create JSON Schemas for composition requests/plans and governed adaptation
   plans; forbid unknown fields where a planner could introduce raw design
   authority.
2. Establish stable IDs, allowed modes/operations, plan version, candidate
   provenance, art-direction style signature and capacity evidence.
3. Add synthetic fixtures and tests that fail before a compiler exists.

**Acceptance:** contracts represent only bounded IDs and fail on raw visual or
free-text directives.

### Task 2: Implement deterministic three-layer composition

**Requirements:** V7-COMPOSE-01
**Depends on:** Task 1
**Slice:** Tracer

1. Resolve candidates only from caller-supplied catalog/observation data.
2. Derive catalog style signatures; require one anchor and explicit compatible
   signature list; calculate compatibility/residue/confidence evidence.
3. Validate `exact_deck`, `page`, and `component` selections and produce
   stable ordered plan output. Exact deck remains the preferred full-deck
   path, page is the default flexible path, component is explicit only.

**Acceptance:** repeated serialization is byte-identical and all unsafe or
incompatible inputs fail closed.

### Task 3: Compile governed adaptation plans

**Requirements:** V7-ADAPT-01
**Depends on:** Task 2
**Slice:** Boundary

1. Validate locked fact/asset registries and intent bindings.
2. Permit only `replace_text` into selected safe text regions and
   `replace_asset` into a declared selected page/component target policy.
3. Reject literal text, raw geometry/style fields, unknown IDs, duplicate
   target references, mode mismatch, insufficient capacity and source changes.

**Acceptance:** output carries only references and safe operation records,
with each record tracing to a selected catalog item and registered input.

### Task 4: Wire CLI, smoke, and close evidence

**Requirements:** V7-COMPOSE-01, V7-ADAPT-01
**Depends on:** Tasks 1–3
**Slice:** End-to-end tracer

1. Add `compose` and `adapt` CLI commands using atomic JSON output.
2. Run focused tests, schema checks, deterministic diff checks and a sanitized
   local private smoke plan.
3. Run gates and a fresh independent audit; resolve every Blocker/Important.

**Acceptance:** AC-51-01 through AC-51-04.

## Rollback And Recovery

- The phase writes no source PPTX or archive state. Remove uncommitted code or
  revert its commit to restore Phase 50 behavior.
- Later materializers must reject absent/invalid governed plans rather than
  falling back to legacy free-form authoring.
