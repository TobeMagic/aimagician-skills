## 3. HTML Presentation Capability

The browser-native presentation contract now supports:

- a single-file `<deck-stage>` player and custom horizontal `#deck > .slide` stages;
- Arrow, Page, Space, Home, End, wheel, and touch navigation;
- `Escape` or `O` overview cards;
- `F` full screen;
- progress, URL hash, persisted position, and print behavior;
- fidelity PPTX export from the live HTML stage through a loopback-only static server;
- explicit separation from native editable PowerPoint ownership.

The exporter starts HTTP automatically because module-based presentations can fail under `file://` CORS rules. It captures each live slide at 1600x900 and packages one image per slide. Editable HTML-first PPTX remains a separate independent-slide pipeline.
