# Release Notes Checker

Verify release notes before they ship.

## Workflow

1. Collect the release notes draft and the commit/tag range it claims to cover.
2. Check every referenced link, issue, and pull request resolves.
3. Compare claims against merged changes; flag missing breaking-change or deprecation notices.
4. Confirm version, date, and product names match the release metadata.
5. Report each finding as pass, warn, or fail with the exact claim and evidence.

## Do not use

- Do not use to write new release notes or draft feature copy; this skill only validates existing notes.
- Do not use for general documentation review or prose editing.

## Guardrails

- Do not approve notes that omit a breaking change or deprecation you can confirm in the code.
